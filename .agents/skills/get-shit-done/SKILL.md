# Get Shit Done (GSD) for Antigravity 🚀

GSD is a spec-driven development workflow system that prevents context rot, model hallucinations, and quality degradation.

## Available GSD Commands & Skills

- `/gsd-super [prompt]` — FULL AUTONOMY: AI builds from prompt to production on its own
- `/gsd-no-halluc [question]` — Technical Q&A with mandatory external research and citations
- `/gsd-commit-memory` — Distill context into long-term memory for future sessions
- `/gsd-new-project` — Set up project vision, requirements, and roadmap
- `/gsd-discuss [N]` — Capture implementation decisions before planning
- `/gsd-plan [N]` — Research and create task plans for a phase
- `/gsd-execute [N]` — Execute plans with atomic git commits
- `/gsd-verify [N]` — Verify built features through user acceptance testing
- `/gsd-quick [desc]` — Execute small ad-hoc task with GSD quality guarantees
- `/gsd-progress` — Pulse check: current state, roadblocks, and next steps
- `/gsd-help` — Show complete command reference and guide
